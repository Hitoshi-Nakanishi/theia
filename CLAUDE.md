## Claude Code Agent

1. Follow every rule in `AGENTS.md`. The git-hygiene rule (no vendor
   identifiers / PII in tracked files) is **mandatory** — re-read it
   before writing any commit message or code constant.
2. Create a git commit at the end of any code change, unless the
   maintainer explicitly says not to.
3. If other pending local changes already exist, stage and commit only
   the files / hunks you changed.
4. Do not include unrelated user changes in your commits.
5. Push only when the maintainer explicitly asks to push.
